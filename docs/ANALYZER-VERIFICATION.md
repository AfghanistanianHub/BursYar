# Evidence analyzer verification — 2026-10-26

Draft follow-up to #2 and #3, tracking #4. No CTO dependency.

## Implemented and locally verified
- Exact source-excerpt checks for criteria, funding and deadline; source HTTPS metadata, SHA-256 digest and unreviewed status. URLs are not fetched.
- Model requests carry untrusted source separately from instructions, request English/Dari/Pashto explanations, and bound output tokens.
- UI sends only source text, URL and language to a same-origin `/api/analyze` contract; never sends a shared server token. English remains alongside translations. Unavailable gateway produces an honest error.
- Optional document availability stays in memory; missing documents trigger a potential mismatch and an institution question. Availability does not prove eligibility. No alternatives or travel predictions are generated by PathFinder.
- Engine binds to loopback only, requires a strong internal token, has a minute limit, 20-call process lifetime development cap and provider timeout.
- `npm test`: 16 passing tests. `npm run build`: passing. Firestore tests are textual assertions, **not emulator validation**.

## Review findings / remaining release blockers
PR #2's original schema accepted ungrounded strings and its shared credential must never be exposed to clients. PR #3's analyzer was a placeholder and proposed Firestore rules were not emulator-tested. Both remain draft.

This implementation is **not an operational end-to-end demo**. Exact quote matching proves traceability, not semantic entailment, authenticity, completeness, or correct classification. A source can itself contain malicious instructions. Prompt tests verify message separation only, not live-model injection resistance. Conflicting deadline detection and translations require further evaluation. PathFinder does not issue `appears to meet` because availability alone cannot establish the extracted requirement; education equivalency remains unknown.

No Meta key, model ID or Firebase service credential is available in this runtime; no Firebase/Meta connector is exposed. Live model format/access/credit and actual Firebase project state remain unverified. No production rules were changed. The same-origin authenticated BFF, verified Firebase identity, durable per-user/global quotas, spending caps and safe public deployment are still blocking. The loopback cap resets on restart and is not a production budget.

Real official scholarship evaluation, bilingual human review, responsive/keyboard browser evidence, Firebase emulator tests and submission recording are outstanding. Existing catalog remains demo-only. No API was deployed or billing upgraded.

Render connector is available but has no selected workspace; service access awaits explicit workspace identification as required by its access instructions.
