# Archived records

This directory holds BursYar's historical working record: mission reports, development checkpoints, hackathon and release paperwork, submission material and superseded plans.

**None of it describes the current release.** Several records contradict each other by design — each mission reported the state of its own branch at its own date, and later missions superseded earlier ones. Where an archived document says "current", read "current on the date in its title".

Current state and reference documentation live in the repository:

- [README.md](../../README.md) — what BursYar is, current status, setup, deployment, limits
- [docs/](../) — maintained reference docs (hosted backend, inference runbook, product requirements, security/privacy, storage, OCR, verification, translation review)

Links inside archived files were written to their original paths. They are kept as historical evidence and are not maintained.
